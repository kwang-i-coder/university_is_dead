# university_is_dead 🎓

[English](README.md) | [한국어](README.ko.md) | [中文](README.zh-CN.md) | **日本語** | [Español](README.es.md) | [Tiếng Việt](README.vi.md) | [Português](README.pt-BR.md)

**Claude で大学の講義を学ぶための指示セットと Obsidian ノートテンプレート。**
講義 PDF を追加したら、`운체 3`（OS 第3章）、`다음`（次へ）、`시험 정리본`（試験まとめ）のような短いコマンドで、スライドの順番どおりに踏み込んだ解説を受けられます。ノートの骨組み、試験まとめ、ELI5 絵本の作成も Claude に任せられます。

> **言語について：** 指示ファイル、テンプレート、コマンド、サンプル Vault は韓国語で書かれており、Claude もデフォルトでは韓国語で回答します。現時点で英語版があるのは、ドキュメントとコントリビューター向けのファイルだけです。この README は英語版の翻訳であり、内容が異なる場合は英語版の README が優先されます。

## できること

| こう言うと | こうなります |
|---|---|
| `운체 3` | 第3章をグループ（1グループにつき核心となる問いが1つ）に分けたマップを示し、続けてグループ1を解説します |
| `운체 3-2` / `다음` | 1つのグループをスライドの順番どおりに、数式、計算過程つきの数値例、セルフチェック問題を交えて解説します |
| `골격 만들어줘` + PDF | `## Section / ### Slide Title (Korean) / - ` 形式の空のノートを作成します |
| `정리해줘` | あなたが書いた内容はそのまま残し、PDF をもとにノートを完成させます |
| `시험 정리본` | ★ による重要度、比較表、採点基準つきの練習問題、試験ポイントの Q&A |
| `/eli5 {ノート}` | 比喩と講義の定義を区別した HTML 絵本 |
| `저장해줘` / `운체 3 전부` | グループ解説を `클코 설명/` にノートとして保存し、最初から最後まで `다음 →` リンクでつなぎます |
| `기출 분석` + 過去問または受験者の試験レビュー | 年度別の問題表、頻出トピック、優先順位を `클코 정리/기출 분석.md` に書き出します |
| （科目ごとの例外に `증명 과목`） | 定理ごとの証明テンプレート、逆とその成立条件の表、過去問形式の模擬試験 |

## 5分でセットアップ

1. このリポジトリを入手します。GitHub で **Use this template** を使うか、Code → Download ZIP でダウンロードしてください。
2. `example-vault/` を参考に、Obsidian の Vault に科目フォルダを作ります。学期フォルダの中に置いてもかまいません。その場合は、科目表にそのフルパスを書いてください。
   ```
   (Vault ルート)/
   ├── CLAUDE.md          ← Claude Code を使う場合（手順 4）
   ├── templates/         ← このリポジトリの templates/ のコピー
   ├── tools/             ← このリポジトリの tools/ のコピー
   └── {科目}/
       ├── 강의자료/        ← 講義 PDF（読み取り専用）
       ├── {講義タイトル}.md  ← 週ごとのノート
       ├── 개념.md          ← 概念ハブ + 週ごとのノート一覧表
       ├── 클코 정리/       ← 試験まとめ、過去問分析
       ├── 클코 설명/       ← 保存したグループ解説
       └── 학습자료/        ← ELI5 HTML
   ```
   PDF のページリンクが正しく機能するよう、各講義 PDF にはノートと同じ名前を付けてください（`1주차 정렬 기초.md` ↔ `강의자료/1주차 정렬 기초.pdf`）。
3. `INSTRUCTIONS.md` を開き、**「📝 여기만 고치세요」**（「ここだけ編集」）ブロックに学校名、受講科目、略称を記入します。科目フォルダは Vault ルートからのパスで書きます（例：`딥러닝/`）。
4. 指示を Claude に渡します。
   - **Claude Projects**：内容を Project instructions に貼り付け、科目フォルダと `templates/` のファイルをプロジェクトナレッジとしてアップロードします。
   - **Claude Code**：`CLAUDE.md` に同じ編集を加え、`CLAUDE.md`、`templates/`、`tools/` を Vault ルートにコピーして、そこから Claude Code を実行します。リンクチェッカーには Python 3.8 以降が必要です。
5. `{略称} 1` と入力してみましょう。

## 基本原則

- **講義資料が唯一の基準です。** スライドにない内容には「교재 보충」（教科書による補足）と明記します。
- **あなたのノートを上書きすることはありません。** Claude は足りない部分だけを、最小限の編集で補います。
- **スライドの順番を守ります。** グループ同士を混ぜることはなく、付録のスライドは独立したグループにまとめます。
- **解説を薄くしません。** 各概念は「動機 → 直観 → 定義/数式 → 数値例 → 限界」の順に説明します。

## ⚠️ 講義資料はアップロードしないでください

教授の講義資料や、講義内容を書き起こしたノートは著作物です。Vault を GitHub にバックアップする場合は、このリポジトリの [`.gitignore`](.gitignore) を使い、公開リポジトリには push しないでください。このリポジトリのサンプルはすべて、新たに書き下ろした架空の講義です。

## コントリビュート

新しいコマンド、ほかの種類の科目向けのルール、テンプレートの改善など、どれも歓迎します。[`CONTRIBUTING.md`](CONTRIBUTING.md) を読み、Issue テンプレート（Bug Report / Enhancement Request / Common Issue）のいずれかで Issue を作成してから PR を送ってください。すべての PR で、指示ファイルの同期、サンプル Vault のリンク、講義資料がアップロードされていないかが自動でチェックされます。
