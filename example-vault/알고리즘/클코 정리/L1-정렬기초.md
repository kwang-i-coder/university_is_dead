# L1. 정렬 기초 — 알고리즘 시험 정리

> 알고리즘 (예시 과목) | 원본 필기: [[1주차 정렬 기초]]
> 시험 형식: 일반 시험 형식 (족보 없음)

---

## 1. 정렬 문제

### 1-1. 정렬의 정의 ★

- **정의**: 수열 $a_1, \dots, a_n$을 받아 $a'_1 \le a'_2 \le \dots \le a'_n$ 을 만족하는 순열을 출력하는 문제
- 💡 비유: 키 순서대로 줄 세우기

### 1-2. Stability (안정성) ★★

- **정의**: 값이 같은 원소들의 입력 순서가 출력에서도 유지되면 stable sort
- **예시**: (3,a), (1,b), (3,c) → stable이면 (1,b), (3,a), (3,c). (3,c)가 (3,a)보다 앞에 오면 unstable

## 2. 단순 정렬 비교 ★★★

| 알고리즘 | 최선 | 평균 | 최악 | Stable | 아이디어 |
|---|---|---|---|---|---|
| Bubble Sort | $O(n)$ (조기 종료 시) | $O(n^2)$ | $O(n^2)$ | O | 인접한 두 원소 교환 |
| Insertion Sort | $O(n)$ | $O(n^2)$ | $O(n^2)$ | O | 앞쪽 정렬된 부분에 하나씩 끼워 넣기 |
| Selection Sort | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | X | 남은 것 중 최솟값을 골라 앞으로 |

**숫자 예시 — Insertion Sort [5, 2, 4, 1]**
1. 2를 꺼내 5 앞에 넣음 → [2, 5, 4, 1] (비교 1번)
2. 4를 꺼내 5 앞, 2 뒤에 넣음 → [2, 4, 5, 1] (비교 2번)
3. 1을 꺼내 맨 앞에 넣음 → [1, 2, 4, 5] (비교 3번)
- 총 비교 6번 = $\frac{n(n-1)}{2} = \frac{4 \cdot 3}{2}$ → 역순에 가까운 입력이라 최악에 가까움

## 연습문제

### 문제 1. Selection Sort가 unstable한 이유를 예시와 함께 설명하시오.

**모범답안**
Selection Sort는 최솟값을 찾아 현재 위치의 원소와 **멀리 떨어진 위치끼리 교환**한다. [(2,a), (2,b), (1,c)]에서 첫 단계에 (1,c)와 (2,a)를 교환하면 [(1,c), (2,b), (2,a)]가 되어 같은 값 2의 원래 순서(a→b)가 뒤집힌다.

**채점 기준**
- 필수 키워드: 교환(swap), 같은 값의 순서가 바뀜
- 부분점수: 원리만 쓰고 예시가 없으면 절반

## 시험 포인트 요약

**Q. 거의 정렬된 입력에 가장 유리한 단순 정렬은?**
A. Insertion Sort. 이미 제자리인 원소는 비교 1번으로 끝나서 최선 $O(n)$.

**Q. 세 단순 정렬 중 unstable한 것은?**
A. Selection Sort.
