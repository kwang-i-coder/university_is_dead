# FAQ

### Claude Projects와 Claude Code 중 뭘 써야 하나요?
- **Claude Projects** (claude.ai): `INSTRUCTIONS.md` 내용을 프로젝트 지침 칸에 붙여 넣고, 과목 폴더를 프로젝트 자료로 연결합니다.
- **Claude Code**: vault 루트에 `CLAUDE.md`를 두고 그 폴더에서 실행하면 지침이 자동으로 읽힙니다. 노트 파일을 직접 만들고 고치는 작업(골격, 정리본, ELI5)에 편합니다.

### 과목 줄임말은 아무거나 써도 되나요?
네. 지침의 "수강 과목" 표에 적은 줄임말이 그대로 명령어가 됩니다. `운체`, `OS`처럼 여러 개를 적어도 됩니다.

### 스캔본 PDF나 그림뿐인 슬라이드는요?
지침의 "그림뿐인 슬라이드도 확인한다" 원칙 때문에 Claude가 페이지를 이미지로 보고 설명합니다. 텍스트가 없다고 건너뛰지 않아요.

### 같은 장에 파일이 두 개예요.
Claude가 어느 파일인지 먼저 묻습니다. 자주 헷갈리는 경우라면 지침의 "과목별 예외" 줄에 적어 두세요.

### ELI5 HTML에서 한글이 깨져요.
파일 맨 앞에 `<!doctype html>`과 `<meta charset="utf-8">`이 있는지 확인하세요. 지침에 이 규칙이 들어 있지만, 직접 고친 파일이라면 빠질 수 있어요.

### 강의자료를 GitHub에 같이 올려도 되나요?
안 됩니다. 교수님 강의자료는 저작물이라 재배포하면 안 돼요. 이 레포의 `.gitignore`는 `강의자료/` 안의 PDF·PPT를 막아 둡니다. 내 vault를 공개 레포로 백업할 때도 같은 `.gitignore`를 쓰세요.

### 족보가 있으면요?
지침의 "시험 자료" 줄에 위치를 적으면 시험 정리본이 그 형식을 참고합니다. 없으면 "일반 시험 형식"으로 만들고 그렇게 표시합니다.
